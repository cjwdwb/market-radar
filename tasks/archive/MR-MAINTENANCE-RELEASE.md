# MR-MAINTENANCE-RELEASE · 2026-11-10

在暂停开发前发布到原站。基线为 GitHub main 6536f7d、公开 Sites v42（8a03215）及已审计的本地候选 f0d2fda。保留既有分支与未完成的数据目标。

1. 修复已复现的 HTTP 429 响应正文损坏或与状态矛盾时，同源第二个标的再次请求的问题。保持取消语义、服务端诊断、有效的更长等待时间和其他供应商刷新。范围为 lib/market-client.ts 与对应测试。
2. 修复页面报价时效与本机提醒实际判断不一致的问题。沿用市场和获取时间门槛，维持提醒、休市及手动周期语义。范围为 lib/market.ts、app/market-radar.tsx、必要的既有展示/测试文件。
3. 修复云监控已暂停时同步本机自选会重新开启的本页交互缺陷，覆盖竞态与失败，不迁移独立服务。集成已审计的 AI 权限修复，生产入口继续关闭。
4. 先做定向回归，再构建、检查类型、运行完整 Node 和受影响浏览器矩阵。独立审计后上传普通 PR，通过 CI 后合并。用同一源码打包到原公开 Sites，核验新入口和受保护路径。不迁移数据库、启用模型、变更秘密或发布代理。
5. 外部图表可用的历史观察与站内实时证据分开。发布验证继承供应商的限流停止条件，不用重复轮询代替恢复凭证。记录用户可走的替代路径、线上实测和仍开放的限制。

## 暂停开发期间

- 站内行情按来源独立退避；已有 429 响应头时，取数、切图和验证新自选共用等待期限。取消旧页面请求保留限流信息。来源本身恢复和真实连续 30 分钟、跨收盘仍须单独验证。若只看盘，图表下有同交易对外部入口。
- 云端同步先读最新开关；检测到其他修改时保留云端状态，用户核对后可重试。独立 monitor 使用整份配置写入，多设备同时管理仍有预读与写入之间的竞态，建议由一个管理页面操作。
- 真实 AI 保持关闭，后台自动模型消费为零。未来启用须另核来源、站主权限、唯一账本，并修复两项受控路径问题：多实例取数前原子预占快照容量、无效凭据不应阻断已有结果的读取。
- 个人文件保存在本机；已发布日频资料可在历史面板读取。供应商许可、连续分钟采集及异地保管保留开放状态。

# BUILDER
读取根 AGENTS.md 和指定任务卡（默认 tasks/ACTIVE.md）；文档按共享路由按需读取。
确认目标、允许路径、基线及现有改动；以 targeted search 定位实现。
按验收做最小修改，发现 scope 冲突时说明具体缺口，不自行扩展产品需求。
运行相关检查；变更影响集成时再扩大测试。审计修复只处理指定 findings。
交接修改路径、测试结果、未解决事项和审计基线；不是协调者时不要覆盖共享 ACTIVE。

# 视觉与交互升级记录

本轮在固定测试行情、相同窗口和相同页面状态下比较。测试数据只在浏览器请求拦截中使用，没有写入生产代码。

## 实测变化

| 视口 | 核心价格顶部 | K 线顶部 | 结果 |
| --- | ---: | ---: | --- |
| 1440 px 桌面 | 638.4 → 476.8 px | 937.9 → 709.6 px | 首屏更快进入行情主体 |
| 390 px 手机 | 635.4 → 475.0 px | 1092.8 → 655.0 px | 首屏可直接看到价格与图表 |

在图表上使用普通滚轮时，页面从 `scrollY=64` 滚动至 `224`，可见 K 线数量保持 60；按住 `Ctrl` 时滚轮用于缩放。这样保留原生页面滚动，也提供明确的图表缩放入口。

## 主要调整

- 合并重复的页面状态，收紧头部、概览和主图表之间的距离。
- 统一背景、面板、边框、间距、控件高度、焦点环和低饱和涨跌色。
- 强化选中标的反馈，减轻空提醒区域的视觉重量。
- 价格数字按实际渲染宽度预留空间；极小价格保留有效精度。
- K 线支持拖动、双指缩放和 `Ctrl + 滚轮` 缩放，并动态计算价格轴宽度。
- 开场和微交互使用有限时长；系统切换到减少动态效果时立即停止装饰动画。
